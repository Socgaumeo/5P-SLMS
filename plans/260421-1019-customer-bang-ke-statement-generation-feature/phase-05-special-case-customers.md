- Brief: Build dedicated renderers for 4-5 customers whose Excel layouts don't fit any of the 4 generic families.

## Customers in scope

| Customer | Reason for custom code |
|---|---|
| **TDI** (Thanh Đạt) | 3 sheets song song: TDI 1, TDI 2, TDI THU CHI HỘ. Multi-sheet with cross-sheet references. |
| **KWE** (Kintetsu) | Data dump format (6 sheets, no standard header). Likely auto-generated by their system. |
| **MESSER** (HD/HP/DQ/TN) | 4 entity codes for same parent. Specific layout, no clear cluster match. |
| **DONSUNG warehouse** | "BẢNG KÊ DỊCH VỤ KHO" — kho-specific (storage), 8 sheets, no cluster match. |
| **NIPPON** | Multi-tab raw data, not standard debit format. |

## Strategy
- **NOT every customer needs custom code**. Some (like TDI BẢNG THEO DÕI) might be internal tracking, NOT debit notes — confirm with user first.
- **MESSER 4 codes** — check if they share format → 1 module covers all 4.
- **TDI** — only template that genuinely needs multi-sheet output beyond Family C/D capabilities.
- **KWE** — may be view-only data sheet (KH self-service), might not need export from DB at all.

## Requirements

### TDI specifically
- 3 sheets in single workbook:
  - Sheet 1: "TDI LÊN HÓA ĐƠN 1" — air shipments part 1
  - Sheet 2: "TDI LÊN HÓA ĐƠN 2" — air shipments part 2
  - Sheet 3: "TDI THU CHI HỘ" — reim only
- Cross-sheet sum formulas (Sheet 3 references Sheets 1+2).

### MESSER 4 entities
- Each has own customer_code (HD/HP/DQ/TN).
- Format: standard debit note (single sheet).
- Likely fits Family B handling — verify against existing T3 file.
